# Experimental NVIDIA performance revision

Changes relative to minee FPS-plan: enable existing parallel prelude recording and parallel GPU writeback merge; enable up to 512 MiB of GPU-local guest windows, subject to the existing 80% VRAM budget guard. Environment overrides remain supported. These windows retain CPU backing, so this is not zero-copy and can increase VRAM usage. Set VICTORY_CARD_WINDOWS_MB=0 to revert that part, or either parallel switch to 0 to isolate regressions. Existing 1080p, RT-off shortcut and retired snapshot cap (now 256 MiB, was 64 MiB) are retained. No hard total RAM cap is implemented. No synchronization was removed. The archive's previous patch file describes earlier changes only.

No Rust toolchain, Windows GPU, or game assets available in this environment; no compile or gameplay verification. 30 FPS is a goal, not a result. The existing benchmark shows 969 ms/frame with experimental RT and 95 ms of guest read waits. The remaining architecture work (zero-copy guest memory, GPU detiling, shader translation and submission overhead) is not implemented. For diagnostics, latest.txt points to the actual run log; send that log after shader warmup and a settled scene. Compare the same scene with each new switch disabled if performance or rendering regresses.

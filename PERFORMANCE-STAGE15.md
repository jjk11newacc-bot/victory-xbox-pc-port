# Stage 15
Based on Stage 14. Draw descriptor fresh-slot membership now uses a fixed 256-entry boolean table instead of a heap vector, linear searches and sorting; ascending slot order is preserved. Shadow retirement uses sorted exact-range membership for batches over 16 entries, retaining pending order and duplicate semantics. Large batches trade a temporary vector for reduced lookup complexity. No changes to synchronization semantics, GPU detiling, wave64 or unified memory architecture. No Rust compiler or Windows GPU testing available. Archive integrity and independent algorithm models only.

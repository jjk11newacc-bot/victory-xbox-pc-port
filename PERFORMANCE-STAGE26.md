# Stage 26: bounded NVIDIA streaming profile
Static source changes, not compiled or GPU tested. NVIDIA launcher enables coordinated budget, exact range union and capability-checked local GPU input heaps. Existing explicit environment overrides remain available. Adaptive texture pacing now applies to early and decoration bake passes as well as normal passes; all use the existing shared frame byte counter and elapsed-time accounting. Slow-frame allowance is reduced from 20 to 8 ms. NVIDIA defaults disable 1.5-second catchup and reduce normal/early/bake budgets. This is a soft limit: one texture operation, queue maintenance, concurrent passes or mandatory uploads may exceed it. Decoration bake quality and streaming convergence may regress; compare against Stage 25. To restore old pacing set VICTORY_ADAPTIVE_BUDGET=0, VICTORY_TEXTURE_CATCHUP=1, VICTORY_TEXTURE_STAGE_MS=250, VICTORY_TEXTURE_STAGE_MB=192, VICTORY_EARLY_TEXTURES_MS=12, VICTORY_BAKE_TEXTURES_MS=1500. Disable local inputs or range union individually with their flags set to 0. No hard process RAM cap, no GPU detiling or full readback redesign, no 30 FPS claim. Existing launcher selects native 1080p and RT off. Benchmark.md reports historical Radeon measurements, not this build.

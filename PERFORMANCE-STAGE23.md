# Stage 23: experimental sparse descriptor refresh
Opt in with VICTORY_SPARSE_DESCRIPTOR_REFRESH=1. Default unchanged.
Previously descriptor refresh used the enclosing span of all views of each host copy, including gaps. The experimental endpoint sweep emits the exact union of views for watched copies, retaining the enclosing span for unwatched or highly fragmented copies. The unwatched interval throttle is bypassed in experimental mode so no split range is skipped. Existing deferred refresh and fences remain intact. A byte-coverage unit test is included. This is not dirty-page GPU detiling. Indirect shader accesses outside declared views may require the old enclosing span; hardware parity is required before enabling by default. Additional range dispatches may outweigh savings. No Rust compiler or GPU testing available.

# Stage 21 — experimental GPU-side guest-buffer comparisons
Set VICTORY_SMALL_CARD_BUFFERS=1 to admit 256 KiB and larger title buffers to the existing GPU comparison path instead of the 1 MiB default. Explicit minimum-MB override wins. Existing card budget and admission checks remain. This can increase resource count, VRAM use and dispatch overhead; compare against the old path. No new comparison algorithm or texture detile kernel. Dead weak references in the card registry are pruned at stats collection. Diagnostics report aggregate declared/compared and published merged span bytes; not exact changed bytes. No fences or writeback ownership changes. Not compiled or tested on hardware.

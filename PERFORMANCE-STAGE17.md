# Stage 17: shader cache reclamation

Stage 16 retained every shader container and translation forever. This revision reclaims cache-only Arc entries during the existing periodic sweep when accounted shader bytes exceed 256 MiB, 64 MiB with less than 4 GiB available RAM, or unconditionally below 2 GiB available RAM. Live pipelines and compilation jobs retain their references. Destruction happens outside the cache lock. Counters now decrement on destruction and exclude standalone warmup translations. Thresholds are reclamation triggers, not hard memory caps; live shaders and other allocations are not capped. Reuse after eviction may incur translation overhead. No compiler or GPU validation performed. GPU detiling and wave64 execution redesign remain unimplemented. The copy queue intentionally retains submitted allocations on uncertain fence completion; this safety path is unchanged.

# Stage 19: dominant mip row-band parallelism
Stage 16 parallelized separate subresources, leaving single-mip and dominant-mip workloads largely serial. Stage 19 splits the largest subresource into two disjoint output row bands when it accounts for at least 75% of selected staging bytes. The original address walker is shared with serial detile and tile, retaining absolute source row coordinates and band-local destination offsets. Linear and depth>1 layouts retain serial conversion. The existing global worker permit bounds concurrency; no second texture-sized allocation. A regression test compares serial and parallel output including padding and mip levels. No compiler or GPU available; tests not executed. Thread startup and repeated column table construction may offset gains. GPU detiling, unified memory redesign and wave64 execution remain incomplete.
